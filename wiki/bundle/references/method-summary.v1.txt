Context-first agent-building principles: establish Agent in a Folder as the durable workspace, build a sourced knowledge base early, then develop prompt by prompt with increasing context. Study API/MCP documentation and actual integration behavior to create skills around verified capabilities. Front-matter metadata helps select appropriate skills. Preserve substantive checkpoints rather than compressed acronyms. Progressive prompting applies throughout. Complete agent design includes deliverables, communication and handoffs, task tracking, routines, bounded autonomy, proactivity and controlled learning. Engineering controls and helper scripts are implementation additions. This repository is a practical tool, not course material.
